# Heart-Stroke-Prediction-Model
Heart stroke risk prediction app built with Python, Scikit-Learn, and Streamlit.  1. Trained and evaluated 5 models (Logistic Regression, Naive Bayes, Decision Tree, SVM, KNN) in Jupyter Notebook. 2. Standardized features and saved model, scaler, and columns using Joblib. 3. Built Streamlit app in VS Code for real-time predictions.
